# Considerations

## Decisions taken in this build
1. **Palette and typefaces.** The interim palette (teal, brick red, gold) and typefaces (Bricolage Grotesque, Figtree) come from the owner's saved design style. They are not yet confirmed as the organization's brand. Change them in the tokens in `styles.css`, then re-run `tools/build.py`.
2. **Display typeface.** The brief asks for a serif display face. The owner's saved style uses Bricolage Grotesque (sans-serif), which was used. A serif can be swapped in with one token (`--f-display`).
3. **Hero line.** A shortened form of the published mission. The full published sentence appears in the Mission panel (SRC-001).
4. **Vision.** No text was supplied, so the panel shows a labelled placeholder with the Draft label. Nothing was written on the organization's behalf.
5. **Story.** No story was supplied and no consent is recorded, so the section shows Consent required and no text.
6. **Photographs.** None supplied. The hero slot is a labelled placeholder.
7. **Comments.** The form validates input and links errors to fields. It does not store or send anything, because the backend is not built. The form says so plainly. No personal data is kept in the browser.
8. **Staff preview.** A `<dialog>` at the hidden route `#staff`. It traps focus and returns focus on close. Labelled as a preview.
9. **Audio.** Not built. Narration is optional and opt-in in the brief; it can be added later with a transcript and a consent record.
10. **Content Security Policy.** `_headers` sets a strict policy for scripts and images, and allows `'unsafe-inline'` for styles. Inline style attributes set the reveal stagger (`--i`); moving those values into the stylesheet would remove this exception.
11. **Google Fonts.** Loaded from Google's servers. This is a third-party request: self-host before launch, or disclose it.
12. **Social links.** Written as `https://www.facebook.com/MialeYaTumaini` and `https://www.instagram.com/MialeYaTumaini` (the source gives them without a scheme).
13. **Kiswahili.** First draft of all interface strings. Needs native speaker review. Aria labels remain in English.
14. **Analytics.** None. If added later, disclose them in the privacy notice.
15. **Icons.** Generated by `tools/build.py` rather than committed as binary files. Run the build before deploying.

## Known gaps against the brief
- Count-up animation for figures: not built. Figures use the reveal motion.
- Speech narration: not built (see 9).
- Comment review queue: an empty preview only.
- Image formats (WebP, AVIF) and responsive sizes: nothing to optimise until photographs are consented.
- WCAG audit, TalkBack and VoiceOver tests, and Lighthouse run: still to do.

## Roadmap
1. Confirm palette and display typeface with the organization.
2. Self-host fonts; apply `_headers`; deploy to a staging domain.
3. Native Kiswahili review; legal review of the privacy notice.
4. Collect vision text, a consented story and consented photographs.
5. Backend (later stage): PostgreSQL tables for comments, consent records, source register and figures, with parameterised queries and row-level access for staff roles.
6. Accessibility audit and performance budget run before launch.
