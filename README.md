# Miale ya Tumaini · Website (front end foundation)

Static site for Miale ya Tumaini, Kware, Ongata Rongai, Kenya. Front end only. Payments and the backend are out of scope for this stage.

## Files
- `index.html`: single page with anchored sections (mission, programmes, impact, story, how we work, visit, comments, privacy, staff preview, footer).
- `styles.css`: design tokens, glass surfaces, motion, layout, reduced-motion rules.
- `app.js`: English and Kiswahili copy, theme switch, comment form validation, staff preview dialog, install prompt, service worker registration. Storage and browser calls are guarded.
- `sw.js`, `offline.html`, `manifest.webmanifest`: install and offline support.
- `sitemap.xml`, `robots.txt`, `_headers`: SEO and hosting headers.
- `sources.json`: source register. Every fact, figure, consent item and status has an entry.
- `tokens.md`: token record with computed WCAG contrast ratios (generated).
- `CONSIDERATIONS.md`: decisions taken, deviations from the brief, and the roadmap.
- `tools/build.py`: generates icons, `tokens.md` and a single-file preview.

## Run locally
1. Build icons and the token record: `python3 tools/build.py`
2. Serve the folder over HTTP (service workers need HTTPS or localhost): `python3 -m http.server 8080`
3. Open http://localhost:8080

## Before launch
Replace every `REPLACE-WITH-DOMAIN` in `index.html`, `sitemap.xml` and `robots.txt`. Icons are generated by `tools/build.py` and must exist before deploy.

## Launch checklist
- [ ] Replace placeholder domain everywhere
- [ ] Generate icons (`python3 tools/build.py`) and confirm both PNGs load
- [ ] Self-host Bricolage Grotesque and Figtree, or disclose the Google Fonts request in the privacy notice
- [ ] Apply `_headers` on the host, served over HTTPS
- [ ] Legal review of the privacy notice; set the retention period
- [ ] Native Kiswahili review of every string in `app.js`
- [ ] Vision statement approved and supplied
- [ ] Family story only after written guardian consent for website use
- [ ] Each photograph only after subject and use consent, with a record ID in `sources.json`
- [ ] Figures 17,000+ and 350+ verified with records, or labelled accordingly
- [ ] Registration number and governance details confirmed before publishing
- [ ] WCAG 2.2 AA audit; TalkBack and VoiceOver test; 200% zoom check
- [ ] Lighthouse run against the performance budget
- [ ] Install prompt tested on Android Chrome; iOS instructions checked
